# Security

RemotePlayCino is a beta remote-access application. Share only with people you trust and limit guest permissions to what is needed. An admitted keyboard/mouse guest can interact with applications available to the host session.

Use current Windows security updates. Build inputs are pinned for reviewability; review runtime, package and native dependency updates regularly. A successful build or analyzer run is not a security certification.

Current EXEs are unsigned. Verify the release SHA-256 before use; this is an integrity check, not publisher identification. Planned SignPath signing is inactive until acceptance and a verified signing run.

Do not attach credentials, access codes, private addresses or unredacted logs to public issues. For a suspected vulnerability, open a minimal issue requesting a private contact channel without publishing exploitation details or personal data. This repository does not claim a separate security mailbox.
