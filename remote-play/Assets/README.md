# Identidad de RemotePlayCino

Nombre de la aplicación y del ejecutable: **RemotePlayCino** (`RemotePlayCino.exe`).

Nombre que acompaña al logo en la cabecera: **RemotePlayCino**.

El símbolo combina una taza de capuchino con un mando, con vapor verde menta, cuerpo crema y café caramelo. `GamepadCino.png` es el original con transparencia. `GamepadCino.ico` contiene tamaños 16, 20, 24, 32, 48, 64, 128 y 256 para Windows; se genera desde el PNG mediante `../Build-BrandIcon.ps1`.

El PNG se generó con la herramienta integrada de imágenes de OpenAI. El icono se obtiene mediante conversión de formato y reducción de tamaño; no se redibuja el diseño. Ambos recursos quedan integrados dentro del ejecutable.
