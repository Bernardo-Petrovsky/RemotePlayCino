# RemotePlayCino

Comparte pantalla, sonido y mandos con baja latencia (Windows 10/11, x64).

Este repositorio solo distribuye los programas ya compilados. Descarga el último
paquete desde la sección **Releases**, descomprímelo en una carpeta y abre
`RemotePlayCino.exe`. La propia aplicación puede buscar versiones nuevas desde
**Ajustes → Buscar actualización**.

El paquete incluye FFmpeg (ver `ffmpeg\LICENSE` y `ffmpeg\README.txt`) y SDL3.
